# Handoff

Last updated: 2026-11-12

## Where things stand

- Wagonmaster Manifest 1.2.1 was written and reviewed in a chat session. It parses and passes the static Pester tests in CI. It has never been run against Azure.
- Wagonmaster Waypoint 0.2.0 (`src/waypoint/`) builds a one file HTML dashboard from a Manifest export. It was built and tested against the two fictional sample exports in `samples/`, with jsdom tests for the template and Pester tests for the script. It has never read a real export.
- Waypoint covers migrations to Azure and to Azure Local. For Azure Local it computes readiness and a cluster sizing estimate itself, because Azure Migrate has no Azure Local assessment, and it tracks `Microsoft.DataReplication` protected items. The Azure Local replication record shape in the sample is from memory of the API and is unverified. The sizing defaults (4 virtual CPUs per core, 20% growth, 32 core 512 GB nodes, three way mirror, one spare node) are placeholders until the owner supplies preferred values.
- The docs site is live at labs.hybridsolutions.cloud/wagonmaster/ through GitHub Pages, with two Waypoint demos built from the samples on every deploy.
- The labs landing page (Hybrid-Solutions-Cloud.github.io) has a Wagonmaster card. Its text describes only Manifest and could be widened to mention Waypoint.
- CI: `validate` runs Pester and PSScriptAnalyzer on Windows and the Waypoint template tests on Ubuntu. `deploy-docs` builds both demos with the real PowerShell script, then the site. Both were green at the last push.

## Decisions already made

- Name: Wagonmaster. Tools: Manifest (early release), Waypoint (dashboard report, preview), Muster (wave planning, planned).
- Waypoint is a single HTML file generated by PowerShell, with no build step and no external dependencies. A browser app is a possible later step.
- Waypoint must surface as much of the export as possible: curated views plus a data explorer for every dataset and field.
- Public repo under Hybrid-Solutions-Cloud, docs on labs.hybridsolutions.cloud via GitHub Pages, VitePress to match hybrid-health-monitoring.
- Not specific to Azure Local or to any employer. Keep examples generic.
